## 📋 O projektu

Toto portfolio slouží jako moje digitální vizitka a profesionální prezentace. Obsahuje informace o mém vzdělání, pracovních zkušenostech, technických dovednostech a realizovaných projektech.

- **Moderní design** - Tmavý režim s plynulými animacemi a přechody
- **Plně responsivní** - Optimalizováno pro všechna zařízení (mobil, tablet, desktop)
- **SEO optimalizované** - Meta tagy, Open Graph, strukturovaná data (Schema.org)
- **Bezpečné** - Implementace Content Security Policy a dalších bezpečnostních hlaviček
- **Vysoký výkon** - Preconnect pro externí zdroje, optimalizované načítání
- **Přístupné** - Sémantické HTML, ARIA atributy
- **Typewriter efekt** - Dynamické zobrazení rolí v hero sekci
- **Interaktivní navigace** - Smooth scrolling mezi sekcemi

## 🚀 Jak spustit lokálně

### Jednoduché spuštění

Protože jde o statický web, stačí otevřít `index.html` v prohlížeči:

```bash
# Naklonování repozitáře
git clone https://github.com/0ndraM/Muj-web.git

# Přechod do složky
cd Muj-web

# Otevření v prohlížeči (Linux/macOS)
open index.html

# Nebo (Windows)
start index.html
```

### S lokálním serverem (doporučeno)

Pro správnou funkci všech funkcí (např. CSP) je lepší použít lokální server:

#### Python 3
```bash
python -m http.server 8000
```

#### Node.js (npx)
```bash
npx http-server
```

#### PHP
```bash
php -S localhost:8000
```

Poté otevřete prohlížeč na `http://localhost:8000`
